What is SNAIL?
=================================
SNAIL (SFA Numerically Accelerated Integration Library) is a python library intended to quickly calculate the high harmonic response of atoms using the Strong Field Approximation (SFA). For more information on what HHG and SFA are, check out my final year report `here <https://github.com/alex-benitez/SNAIL/blob/main/SNAILReport.pdf>`_. 

The ethos for SNAIL is ease of use at any scale, it is a package intended to just as readily generate ML-scale datasets, as quickly get an idea of what an experiment should look like. This is still a work in progress, and any feedback is appreciated; for any questions, comments or suggestions, please email me at `alexbenitezcanelles@gmail.com <mailto:alexbenitezcanelles@gmail.com>`_.
